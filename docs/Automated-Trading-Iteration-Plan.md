# A股推荐策略迭代计划

## 短线隔夜并行研究（15.3.0）

为避免把不同交易逻辑混在同一组参数中，短线研究拆成三个相互独立的流，并由后台线程池并行计算：

1. 尾盘突破：收盘突破近 20 日高点且放量；
2. 尾盘回踩：趋势向上、回踩短均线后收阳；
3. 强势换手/隔夜：放量且收盘强于开盘。

三条流统一采用“收盘产生信号、次日开盘成交、再下一交易日开盘退出”的 T+1 代理规则，单独统计交易数、胜率、平均/中位净收益，并保留滑点和交易费。结果写入 `assets/data/overnight_iterations/latest.json`，不直接改变正式评分或推荐。

当前全市场并行结果（2026-10-16）：

- 突破：3,190 只股票、61,382 笔交易，平均净收益 -0.7018%；
- 回踩：3,199 只股票、206,319 笔交易，平均净收益 -0.3578%；
- 强势换手：3,193 只股票、51,416 笔交易，平均净收益 -0.6352%。

三条流目前均为负，说明不能直接作为实盘策略。结果是日线代理，无法还原尾盘集合竞价、盘口排队、次日开盘成交、涨跌停和盘中止损；必须补齐 1/5 分钟数据、可成交性和样本外滚动验证后，才可进入候选策略晋级。

## 盘后深度采集与对抗校验（15.4.0）

盘后可显式启用深度模式：

```bash
POST_CLOSE_DEEP=1 ./run.sh all
```

该模式会将研究窗口扩展到约 2,500 个交易日，增加网络重试和超时，降低并发以减少服务端拒绝，并将最终候选的公开财务补充范围扩大到 30 只。盘中默认模式不受影响。

深度模式仍遵循收敛规则：数据必须通过质量门、跨源校验和样本外验证；策略只在参数扰动、成本扰动和市场阶段切片后仍保持正向时进入候选，不因单次回测结果直接改变正式评分。

更新时间：2026-10-16（v15.4 对抗整理）

## 短线 vs 长线（必须分开分析）

| 轨道 | 研究 horizon | 看什么 | 不看什么 |
|------|--------------|--------|----------|
| **短线** | `short` + 隔夜三流 + **激进板三流并行** + 正式 short/aggressive | T+1、反追涨、容量、隔夜/激进代理边 | 当日涨停事后点名是否「成功」 |
| **长线** | `medium` / `long`（含 `long_quality_trend_gate`） | 点时财务质量门、长持有组合路径、回撤 | 短线涨幅榜、远东类追涨样本 |
| 波段对照 | `swing` | 仅对照；常为全局 `selected_*` | **不得**代表短线或长线已就绪 |

产物：`assets/data/horizon_analysis/{latest,short,long,swing}.json`

## 本轮研究动作（v15.3 → v15.4）

对抗校验确认：信号边常在组合容量下消失。v15.2 已加上同日限流与组合级晋级门禁。  
v15.3 **预登记**稀疏入场假设族（低波回踩、量能确认、快速退出、限波 TSMOM），阈值冻结后重跑，禁止在同一 OOS 上调参。正式推荐仍须组合级 + 政策双重通过。

**v15.4 对抗调整（不放宽同窗 OOS）：**

1. 晋级：`rejected_capacity > 5 * accepted` 直接否决（容量饥渴不可晋级）。
2. 推荐：量价/分时拆开；分时任务只服务量价已过标的，消除鸡生蛋空推荐。
3. 漏检：`miss_audit` 明确——远东类当日大涨未荐是**反追涨设计**，不是晋级误杀；研究抓先验信号日，不追收盘后涨幅。

## 产品范围（已收窄）

**当前方案只做推荐策略。**

- 输出：全市场选股推荐、操作区间、风险检查、失效条件
- 校验：本地纸面执行模拟（T+1、涨跌停、停牌、滑点、部分成交、费用）
- **不做**：券商接口、自动报单、真实账户联动

真实买卖由人工在券商客户端完成；系统不持有下单权限。

## 最终目标

确定性策略完成选股后，结合行情与纸面风控，输出包含标的、建议动作、价格条件、有效期、策略版本、风险检查和失效条件的**推荐指令契约**。AI 只用于发现数据源、解析非结构化公告和处理采集异常，不参与正式评分或推荐决策。

## 长期策略重构（15.2.0）

长期候选已拆成三个确定性层：

1. 基本面准入：收入增长、利润增长、经营现金流和资产负债率必须按点时数据可验证；字段缺失直接拒绝，不由AI补值。
2. 中线择时：只在上升或震荡状态、价格位于MA60上方、MA20高于MA60且60日动量为正时产生信号。
3. 风险退出：最大持有60日、10%初始止损、跌破MA20退出；基本面退出要求收入、利润和经营现金流同时恶化，避免单季度噪声。

新候选 `long_quality_trend_gate` 已加入候选空间，但在历史财务字段完成同日点时连接前会失败关闭，不会退化成纯技术策略。它必须经过五年样本外、完整市场状态和冻结前向窗口后，才允许替代当前波段候选。
