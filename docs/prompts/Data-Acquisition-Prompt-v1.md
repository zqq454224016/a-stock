# 数据获取 AI Prompt v1

该 Prompt 只服务于后台自动迭代中的“数据获取方法设计”，不参与策略、评分、预测或交易。

源文件：`quant_system/ai/prompts/data_acquisition.py`

## Prompt 组成

1. `PLANNER_PROMPT`：生成严格 JSON 数据获取计划。
2. `REVIEW_PROMPT`：用于后续双模型或二次审查。
3. `validate_plan`：确定性权限和字段校验。
4. `score_plan`：100 分契约评分，低于 85 分不得发布。
5. `render_plan_markdown`：只渲染通过结构校验的内容。

## 评分

| 维度 | 分值 |
|---|---:|
| 权限范围 | 30 |
| 证据路径 | 20 |
| 时间语义 | 15 |
| 增量执行 | 15 |
| 质量与回退 | 10 |
| 验收条件 | 10 |

存在策略修改、交易动作、凭证要求或 scope 越权时，权限范围直接为 0，并判定失败。

## 迭代方法

每次只使用真实缺口样本评估：

- 历史 K 线不足；
- 财务接口无权限；
- 停复牌或除权字段缺失；
- 数据日期覆盖不一致；
- 接口限流和增量游标未知。

评估失败时保留原始响应和错误，不进入正式建议文件。只有缺口指纹变化或冷却期到期才重新调用，防止通过反复 Prompt 试验产生选择偏差。
